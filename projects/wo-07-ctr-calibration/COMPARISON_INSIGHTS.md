# WO-07 · Criteo 주 실험과 Avazu 독립 검증의 비교

## 비교 질문과 설계

첫 실험은 Criteo Click Logs의 제한된 날짜별 조각에서 **보정이 AUC를 유지하며 확률 오차를 줄이는가**를 확인했다. 이후 Avazu 로그를 확보해 **그 관찰이 다른 광고 로그의 뒤쪽 날짜에도 나타나는가**를 별도 검증했다. Avazu는 기존 모델을 같은 테스트셋에 다시 실행한 버전이 아니다. 데이터 출처, 피처, 학습량, LightGBM 설정이 다르므로 두 실험의 AUC·LogLoss·ECE 절댓값으로 개선율을 계산하지 않는다.

| 비교 항목 | Criteo 주 실험 | Avazu 독립 검증 |
|---|---|---|
| 출처 | 공식 Criteo Click Logs | Kaggle Avazu 대회 로그 |
| 원본 확인 | 고정 Parquet 조각 4개, 총 3,010,082행 | 압축 파일 전체 40,428,967행, SHA-256·시간 순서 확인 |
| 실험 입력 | 날짜별 조각 앞부분 총 160,000행 | 클릭 라벨을 보지 않는 ID 해시 표본 1,010,516행 |
| 학습 / 보정 / 평가 | 80,000 / 40,000 / 40,000행 | 596,330 / 213,049 / 201,137행 |
| 평가 표본 클릭률 | 3.11% | 16.35% |
| 피처·기준 모델 | 수치형 13개·범주형 26개, LightGBM 120개 트리 | 범주형·시간 파생 피처, LightGBM 160개 트리 |
| 공통 통제 | 학습 → 보정 → 최종 평가의 날짜 경계; 평가 레이블은 모델 적합에 사용하지 않음 | 학습 → 보정 → 최종 평가의 날짜 경계; 평가 레이블은 모델 적합에 사용하지 않음 |

## 같은 데이터셋 안에서 확인한 변화

아래 `ECE 감소`와 `LogLoss 감소`는 **각 데이터셋의 기준선에서 해당 보정법을 뺀 값**이다. 양수는 개선을 뜻한다. AUC 변화는 보정값에서 기준선을 뺀 값이다.

| 데이터셋 | 보정법 | 평가 AUC 변화 | LogLoss 감소 | ECE 감소 | 보정 후 ECE |
|---|---|---:|---:|---:|---:|
| Criteo | Platt | 0.000000 | 0.004578 | 0.006875 | 0.002513 |
| Criteo | Isotonic | -0.001286 | 0.004467 | 0.006864 | 0.002525 |
| Avazu | Platt | 0.000000 | 0.000401 | 0.003230 | 0.009273 |
| Avazu | Isotonic | -0.000172 | 0.000747 | 0.008327 | 0.004175 |

근거: [Criteo 원 지표](results/metrics.csv), [Avazu 원 지표](results/avazu/metrics.csv), [Avazu 날짜별 지표](results/avazu/per_day_metrics.csv), [Avazu 부트스트랩·원본 감사](results/avazu/report.json).

## 관찰 → 근거 → 깨달음

1. **Platt는 두 실험에서 순위를 유지하면서 확률 오차를 줄였다.** Criteo 평가 AUC는 기준선과 Platt가 모두 `0.668754`, ECE는 `0.009388 → 0.002513`이다. Avazu에서도 AUC가 모두 `0.721701`, ECE는 `0.012503 → 0.009273`이다. 단조 매핑이 순위를 보존한다는 성질과 실제 측정값이 일치한다. **깨달음:** CTR을 입찰 확률로 쓸 때 AUC만으로 보정 품질을 판단할 수 없다.
2. **관측된 최저 ECE의 보정법은 달랐다.** Criteo에서는 Platt `0.002513`, Isotonic `0.002525`로 차이가 `0.000011`에 불과하다. 이 차이에 대한 신뢰구간을 계산하지 않아 Criteo에서 Platt의 통계적 우월성을 주장하지 않는다. Avazu에서는 Isotonic `0.004175`, Platt `0.009273`이며, 두 평가 날짜 모두 Isotonic의 ECE·LogLoss가 더 낮았다. 기준선 대비 ECE 감소의 날짜별 층화 부트스트랩 95% 구간은 Platt `0.001898–0.004475`, Isotonic `0.006557–0.009134`이다. **깨달음:** 보정법 선택은 독립 보정 구간과 뒤쪽 평가 구간의 분포에서 다시 검증해야 한다.
3. **Isotonic의 확률 지표 개선에는 순위 손실이 동반됐다.** Criteo AUC 변화는 `-0.001286`, Avazu는 `-0.000172`다. 계단형 매핑이 예측 동점을 만들 수 있다는 메커니즘과 일치하지만, 두 결과만으로 AUC 손실의 원인을 단정할 수는 없다. **깨달음:** LogLoss·ECE와 AUC를 함께 보고, 사용 목적에 따라 허용 가능한 순위 손실을 결정해야 한다.
4. **검증 근거는 넓어졌지만 데이터 효과를 분리한 실험은 아니다.** Avazu에는 전체 원본 감사, 더 큰 평가 표본, 두 날짜별 결과, 400회 부트스트랩이 추가됐다. 동시에 관측 클릭률과 피처·모델 설정이 달라졌다. **깨달음:** 외부 로그에서 같은 보정 방향을 관찰한 것은 유용하지만, 더 높은 Avazu AUC나 더 낮은 절대 ECE를 Criteo 모델의 개선으로 표현하면 안 된다.

## 해석 경계와 다음 검증

두 로그 모두 클릭·비클릭이 서로 다른 방식으로 부분 표본화됐다. 표본 클릭률은 실제 운영 CTR이 아니고, 가정 클릭 가치의 집계 오차 감소는 광고비 절감이 아니다. Avazu의 부트스트랩은 적합 모델을 고정한 조건부 구간이며 새 기간·모델 재학습의 변동은 포함하지 않는다.

**다음 단계:** 같은 모델 용량과 전처리 규칙으로 데이터셋별 반복 날짜 분할을 수행하고, 예측 구간·광고 유형별 ECE와 AUC를 함께 점검한다. 이 실험으로 보정법 차이의 원인을 더 분명히 분리할 수 있다.
