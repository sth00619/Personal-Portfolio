# 측정 경계

Criteo 주 실험의 수치는 Click Logs에서 날짜별 Parquet 조각 하나의 앞 40,000행씩, 총 160,000행을 선택한 부분 표본에서 계산했다. 공식 배포 설명에 따르면 클릭과 비클릭이 서로 다른 비율로 부분 표본화되어 있다. 따라서 표본 클릭률과 이 모델의 확률은 원래 광고 트래픽의 절대 CTR로 해석할 수 없다.

최종 테스트는 마지막 날짜의 40,000행이다. AUC는 클릭과 비클릭을 얼마나 잘 순위화하는지, LogLoss는 개별 확률의 벌점을, ECE는 10개 동일 폭 구간의 관측 클릭률과 평균 예측 확률의 절대 차이를 표본 수로 가중한 값이다. ECE는 구간 설정에 민감하며, 작은 ECE만으로 모든 세그먼트의 보정을 보장하지 않는다. 그래프에는 낮은 CTR 구간을 읽기 위해 20개 동일 인원수 구간을 사용했다. 그래프와 ECE는 구간 정의가 다르다.

가상 입찰 분석에서 클릭 1회의 가정 가치는 **1,000 KRW**다. 각 행의 가상 입찰가는 `1,000 × 예측 CTR`, 예측 클릭 가치 총액은 `1,000 × Σ 예측 CTR`, 관측 클릭 가치 총액은 `1,000 × Σ 실제 클릭`이다. 집계 편향은 두 총액의 차이이고 절대 추정 오차 proxy는 편향의 절대값이다. 이는 같은 test 표본에서 예측한 클릭 가치의 **합계 오차**이며 실제 지출, ROI, 낙찰가, 절감액이 아니다. 양수와 음수의 개별 오차가 상쇄될 수 있어 이 proxy가 낮아졌다고 모든 입찰 결정이 개선됐다고 할 수도 없다.

실제 입찰 성과를 평가하려면 낙찰가, 경매 승패, 지불 방식, 경쟁 입찰과 실제 트래픽의 표본화 확률이 필요하다. 다른 날짜와 더 많은 조각을 통한 반복 측정도 필요하다.

Avazu 독립 검증은 Kaggle 대회 로그 원본 40,428,967행을 감사하고 ID 해시로 선택한 1,010,516행을 사용했다. 최종 평가 201,137행은 학습·보정 날짜와 겹치지 않는다. Avazu에도 클릭·비클릭 비대칭 표본화가 적용되어 있으며, Criteo와 피처·기본 클릭률이 다르다. 두 데이터셋의 점수 크기를 직접 비교하지 않는다. 부트스트랩 구간은 테스트 날짜 안의 행을 재표본추출하고 적합된 CTR 모델과 보정기를 고정한 조건부 구간이다. 모델 재적합과 새로운 날짜의 불확실성은 포함하지 않는다.
