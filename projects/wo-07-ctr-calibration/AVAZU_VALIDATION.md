## 출처와 원본 확인

- 출처: [Kaggle Avazu CTR Prediction](https://www.kaggle.com/competitions/avazu-ctr-prediction/data)의 `train.gz`
- 이용 조건: [Competition Rules](https://www.kaggle.com/competitions/avazu-ctr-prediction/rules). 원본 및 추출 표본은 Git에서 제외한다.
- 로컬 파일: `data/avazu_train.gz` (사용자가 직접 다운로드한 파일의 사본)
- 압축 크기: **1,117,527,809 bytes**
- SHA-256: `2884596ea9351c8a9abc02bff1f7a4f0d161eac8caceadaaccfff31ec638b4ca`
- `gzip -t` 통과. 헤더의 24개 필드, 클릭 이진값, 시간 순서와 10개 날짜를 전체 스캔했다. 시간 역순 행은 0건이다.

원본의 `id`는 모델 입력에서 제외하고, 표본 선택에만 사용했다. 전체 원본 **40,428,967행 / 클릭 6,865,066건** 중 `crc32(id) % 40 == 17`에 해당하는 **1,010,516행 / 클릭 171,672건**을 선택했다. 해시 선택은 클릭 라벨을 사용하지 않는다.

## 분할과 모델

| 구간 | 날짜 코드 | 표본 노출 | 클릭 |
|---|---|---:|---:|
| 학습 | 141021–141026 | 596,330 | 103,921 |
| 확률 보정 | 141027–141028 | 213,049 | 34,872 |
| 최종 평가 | 141029–141030 | 201,137 | 32,879 |

원본의 시간 순서를 유지하고 날짜가 다른 세 구간으로 나눴다. 원본 10일은 전부 검사했고, 표본에 모든 날짜가 포함된다. 훈련에서 빈도 20회 이상인 범주를 열마다 최대 512개만 남겼다. 범주 목록은 학습 구간에서만 만들고 이후 처음 보는 값은 `__OTHER__`로 바꿨다. `id`와 절대 날짜는 모델 피처에서 제외했다. 시간대와 요일은 문맥 피처로 썼다. LightGBM 160개 트리와 두 보정기는 고정된 설정으로 적합했다.

## 독립 평가 결과

| 방법 | AUC | LogLoss | ECE (10개 동일 폭 구간) |
|---|---:|---:|---:|
| 기준선 | 0.721701 | 0.401317 | 0.012503 |
| Platt | 0.721701 | 0.400916 | 0.009273 |
| Isotonic | 0.721530 | 0.400570 | 0.004175 |

두 평가 날짜 각각에서 Platt·Isotonic의 LogLoss와 ECE가 기준선보다 낮았다. 기준선 대비 ECE 감소는 Platt **0.003230**(95% 부트스트랩 **0.001898–0.004475**), Isotonic **0.008327**(**0.006557–0.009134**)이다. LogLoss 감소는 Platt **0.000401**(**0.000314–0.000496**), Isotonic **0.000747**(**0.000291–0.001035**)이다. 평가는 날짜별 층화 행 재표본추출 400회로 계산하고 적합된 모델을 고정했다.

측정 원본은 `results/avazu/report.json`, `metrics.csv`, `per_day_metrics.csv`, `calibration_curve.png`다. Criteo 실험과 데이터 출처·피처·기본 클릭률이 다르므로 AUC·LogLoss·ECE의 크기를 직접 비교해 모델 우위를 판단하지 않는다. Avazu의 비클릭과 클릭도 서로 다른 방식으로 부분 표본화되었다고 [대회 데이터 설명](https://www.kaggle.com/competitions/avazu-ctr-prediction/data)은 밝힌다. 측정 클릭률은 운영 트래픽의 절대 CTR이 아니다.
