# WO-02 error analysis

이 문서는 검색 실패와 생성 실패를 서로 다른 단계의 문제로 분리한다. 원본 사례와 전체 집계는 [`failure_analysis.json`](failure_analysis.json)에 있다.

## 판정 기준

- **검색 실패**: Hybrid+rerank 상위 10개 문서에 SciFact 정답 문서가 하나도 없는 경우
- **생성 실패**: 정답 문서가 상위 10개에 있지만, 최종 답변이 정답 문서를 인용하지 않거나 SUPPORT/CONTRADICT 판정이 사람 라벨과 다른 경우
- **성공**: 정답 문서를 검색했고, 정답 문서의 문장을 인용했으며, 판정도 사람 라벨과 일치한 경우

## 검색 실패

전체 300개 검색 질의 중 53개가 Hybrid+rerank Recall@10 기준으로 실패했다.

| Query ID | 질의 요약 | 정답 문서 | 관찰 |
|---|---|---|---|
| 1 | 0-dimensional biomaterials | 31715818 | `inductive properties`처럼 짧고 추상적인 표현이 여러 생체재료 문서와 겹쳐 정답이 밀렸다. |
| 13 | low birth weight와 perinatal mortality 5% | 1606628 | 숫자와 의학 용어는 일치하지만, 비슷한 주제의 문서가 상위권을 차지했다. |
| 132 | aspirin inhibits PGE2 | 7975937 | 짧은 관계 질의에서 동의어와 기전 표현을 충분히 연결하지 못했다. |
| 213 | CRP와 CABG 수술 후 사망률 | 13625993 | 부정 표현(`not predictive`)과 복합 임상 조건을 함께 맞추지 못했다. |
| 239 | cellular aging과 older appearance | 14079881 | 넓은 의미 유사도는 잡았지만 정답 논문의 구체 관계를 구별하지 못했다. |

개선 우선순위는 의료·생명과학 검색 데이터로 학습한 임베딩/리랭커 교체, 제목과 본문 필드 가중치 분리, 숫자·부정어를 보존하는 lexical query expansion이다. 현재 리랭커는 MS MARCO 웹 검색 데이터에 맞춰져 있어 SciFact의 과학 주장 검증과 도메인이 다르다.

## 생성 실패

30개 생성 평가 질문은 모두 상위 10개 안에서 정답 문서를 찾았지만 13개가 생성 단계에서 실패했다. 유형별 실패는 계산형 4/10, 비교형 3/10, 사실 조회형 6/10이다.

| Query ID | 유형 | 정답 순위 | 정답 → 예측 | 실패 원인 |
|---|---|---:|---|---|
| 3 | calculation | 6 | SUPPORT → CONTRADICT | 1위 비정답 문서만 생성 컨텍스트로 사용해 잘못된 문서를 인용했다. |
| 5 | calculation | 1 | SUPPORT → CONTRADICT | 정답 문서를 인용했지만 로컬 NLI 모델이 수치 관계를 반대로 판정했다. |
| 279 | calculation | 1 | SUPPORT → CONTRADICT | 유전체 길이 수치가 있는 근거를 찾았으나 판정 모델이 SUPPORT를 놓쳤다. |
| 593 | calculation | 1 | SUPPORT → CONTRADICT | 기간·성별·변화율이 결합된 문장을 NLI 모델이 잘못 판정했다. |
| 51 | comparison | 2 | CONTRADICT → SUPPORT | 1위 비정답 문서를 선택해 방향이 반대인 결론을 냈다. |

생성기는 인용의 정확도를 높이기 위해 상위 1개 문서만 사용한다. 이 선택은 여러 문서를 넣었을 때 비정답 문장을 과신하던 문제를 줄였지만, 정답이 2위 이하인 질문에서는 근거 선택 기회를 없앴다. 다음 개선은 상위 문서별 NLI 점수와 검색 점수를 함께 보정하고, 숫자·부정·비교 관계를 별도 규칙으로 검증하며, 정답 가능성이 낮으면 답변을 보류하도록 만드는 것이다.

## 단계별 결론

검색 단계는 BM25보다 Hybrid+rerank가 Recall@10 **5.21%p**, nDCG@10 **5.82%p** 높아 Ship Gate를 통과했다. 다만 RRF 뒤에 리랭커를 붙이면 RRF 단독보다 Recall@10이 1.49%p, nDCG@10이 0.62%p 낮아졌다. 현재 데이터에서는 **Hybrid RRF를 기본 검색기로 사용하고, 리랭커는 도메인 적합 모델로 교체한 뒤 다시 검증**하는 편이 타당하다.

생성 단계는 인용 포함률과 추출 근거 일치율이 모두 1.0이지만, 정답 문서 인용 정확도는 0.8333, 복합 faithfulness는 0.5667이다. 즉 출처 형식은 지켰지만, 검색된 여러 후보 중 올바른 근거를 고르고 판정을 내리는 능력이 다음 병목이다.
