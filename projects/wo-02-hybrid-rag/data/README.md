# Data

Run `python data/download.py` to download the official BEIR SciFact archive. The downloader validates BEIR's published MD5 checksum before extracting into the Git-ignored `data/scifact/` directory.

`questions.json` selects 30 test claims whose SciFact metadata contains human-authored evidence and SUPPORT/CONTRADICT labels. The selection is balanced across factual lookup, comparison, and numeric/calculation-style claims. Question wording is produced deterministically from the original claim; labels are never generated by a model.

- [BEIR dataset registry](https://github.com/beir-cellar/beir/wiki/Datasets-available)
- [SciFact license](https://github.com/allenai/scifact/blob/master/LICENSE.md): claims and annotations are CC BY 4.0; corpus abstracts are ODC-By 1.0.
