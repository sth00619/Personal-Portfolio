# 원본 데이터 검증 기록

## 출처와 무결성

- 원 배포 정보: [iPinYou data release](https://contest.ipinyou.com/data-release.html), [필드 문서](https://contest.ipinyou.com/ipinyou-dataset.pdf)
- 접근 가능한 원본 보관본: [Figshare season 2](https://figshare.com/articles/dataset/ipinyou_contest_dataset_season2/5732328), 파일 ID `10082688`
- 사용 조건: 원 배포처의 비상업 사용 조건 적용; 원본 파일은 Git에 포함하지 않음
- `data/download.py`는 ZIP의 압축 멤버 바이트 범위를 요청하고 `Content-Range`, 길이, 체크섬을 검사한다. 실험 시작 시 모든 입력의 체크섬을 다시 검사한다.
- 세 학습·보정 접두 파일은 각각 16,787,216바이트로 고정했고 SHA-256을 기록했다. 네 클릭 로그와 전체 평가 노출 로그는 보관본의 `files.md5`와 MD5가 일치했다. 전체 평가 노출 로그 MD5는 `378754f00fa69784b19c5db6305783cc`다.

## 관측 범위

`imp` 파일은 기록된 낙찰 노출이며 모든 입찰 요청의 가격을 포함하지 않는다. 이 실험은 가격이 있는 행에서만, 기록된 입찰가 이하로 입찰을 낮추는 정책을 평가한다. 따라서 낙찰가 CDF는 전체 요청의 무조건부 승률이 아니다. 접두 분할은 압축 데이터의 고정된 앞부분을 완전한 BZip2 블록까지만 해제한 뒤 미완성 행을 버린다. 원본과 행별 파생 데이터는 재배포하지 않는다.
