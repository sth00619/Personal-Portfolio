## 판단 장면 1 — 시간처럼 보이는 변수를 시간으로 부르지 않기

- **상황**: 데이터에는 실제 신청 타임스탬프가 없지만 안정성 비교 코호트가 필요했다.
- **선택지**: `DAYS_BIRTH`/`DAYS_EMPLOYED`로 구간화, 무작위 분할, `SK_ID_CURR` 순서 코호트, 프로젝트 중단.
- **근거**: 날짜 파생 변수는 고객 생애주기 특성이어서 분할 축과 피처 의미가 섞인다. ID도 시간이라는 보장은 없지만 식별자를 모델 입력에서 제외한 채 결정론적 코호트를 만들 수 있다.
- **결정**: ID 오름차순 80/20을 사용하되 결과 명칭을 “분포 스트레스 테스트”로 제한했다.
- **대가**: 운영 시간 드리프트와 재학습 주기는 주장할 수 없다.

## 판단 장면 2 — 라이브러리 이름보다 PSI 계산 계약을 재사용

- **상황**: 작업 문서는 WO-06의 `optbinning` 재사용을 제안했지만 WO-14에는 WoE 구간화가 없다.
- **선택지**: 불필요한 패키지 의존성 추가, 직접 PSI 구현, PSI 생략.
- **근거**: 기준 코호트 분위 구간, 결측 독립 구간, 평활 상수를 공개하면 수치 재현과 코드 감사를 동시에 할 수 있다.
- **결정**: `src/stability.py`에 PSI를 직접 구현하고 동일 분포·이동·결측 시나리오를 테스트했다.
- **대가**: 다른 구현체와 비교할 때 구간·평활 계약을 함께 확인해야 한다.

## 판단 장면 3 — 예상과 반대인 고결측 결과를 그대로 채택

- **상황**: 결측률 50% 이상 집계 피처 6개를 제거했는데 평균 PSI가 0.000003 높아졌다.
- **선택지**: 가설에 맞는 다른 요약값 선택, 변화 없음으로 숨김, 구성 효과까지 공개.
- **근거**: 제거 대상의 평균 PSI는 0.000118로 포함 모델 전체 평균 0.000233보다 낮았다. 낮은 값이 분모에서 빠지면 평균이 오르는 것이 자연스럽다.
- **결정**: 두 번째 가설을 기각하고, 축소 모델 선택 이유는 PSI 개선이 아니라 입력 6개 축소와 ROC-AUC +0.0826%p로 기록했다.
- **대가**: “결측 제거가 안정성을 개선했다”는 단순 서사는 사용할 수 없다.

## GitHub/Notion 반영 요청

1. 루트 README 프로젝트 목록에 WO-14 한 줄을 추가한다.
2. 상세 설명에는 조인 전후 ROC-AUC와 PSI 변화, 실제 시간 검증이 아니라는 경계를 함께 쓴다.
3. `results/auc_psi_tradeoff.png`, `results/top_10_psi.png`, `results/missing_ablation.png`를 시각 자료로 사용한다.
4. “PSI 악화 확인”이라고 쓰지 않는다. 결과는 평균 +0.000085이고 모든 피처가 0.25 미만이다.
5. WO-06과의 차이를 단일 테이블/다중 테이블, 스코어카드 비교/조인 안정성 비교로 명시한다.
