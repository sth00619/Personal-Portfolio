# Data

`cases.json` contains 30 entirely synthetic insurance claims generated by `python data/generate.py`. There are 10 payable, 10 denied, and 10 incomplete cases. Five payable cases include a supplemental receipt that forces one reviewer return. The `gold_terminal` field is a deterministic evaluation label, not an insurance adjudication rule or human judgment. No real claimant data, raw third-party dataset, or PII is used.

Regenerate with `python data/generate.py`; no download is required. The replay harness applies scripted approvals to payable cases, clearly marked as synthetic. The engine itself pauses at `AWAITING_APPROVAL` until a separate `decide()` call provides an actor and decision.
